# Real Store Mode

Internal maturity mode on **Rob’s Desk** (no new menu).

## Shows

- Store maturity gates (10k analyzed, catalog size, QA, automation, admin time)
- Automation Score per domain + admin minutes/day
- Catalog quality issues (action-only)
- Performance problems (action-only)
- Nightly AI Review (what went well/bad/improve/learned)

## Code

`lib/real-store/` · API `GET /api/admin/real-store` · `DeskRealStorePanel`
